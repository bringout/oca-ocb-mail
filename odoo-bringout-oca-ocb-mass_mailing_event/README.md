# Mass mailing on attendees


Mass mail event attendees
=========================

Bridge module adding UX requirements to ease mass mailing of event attendees.
        

## Installation

```bash
pip install odoo-bringout-oca-ocb-mass_mailing_event
```

## Dependencies

- event
- mass_mailing
