# Mass mailing on course members


Mass mail course members
========================

Bridge module adding UX requirements to ease mass mailing of course members.
        

## Installation

```bash
pip install odoo-bringout-oca-ocb-mass_mailing_slides
```

## Dependencies

- website_slides
- mass_mailing
