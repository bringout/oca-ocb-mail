# SMS gateway


This module gives a framework for SMS text messaging
----------------------------------------------------

The service is provided by the In App Purchase Odoo platform.


## Installation

```bash
pip install odoo-bringout-oca-ocb-sms
```

## Dependencies

- base
- iap_mail
- mail
- phone_validation
