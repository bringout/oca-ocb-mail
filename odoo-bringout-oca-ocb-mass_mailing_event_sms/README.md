# Event Attendees SMS Marketing


SMS Marketing on event attendees
================================

Bridge module adding UX requirements to ease SMS marketing o, event attendees.
        

## Installation

```bash
pip install odoo-bringout-oca-ocb-mass_mailing_event_sms
```

## Dependencies

- event
- mass_mailing
- mass_mailing_event
- mass_mailing_sms
- sms
