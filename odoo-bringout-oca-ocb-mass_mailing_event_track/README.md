# Mass mailing on track speakers


Mass mail event track speakers
==============================

Bridge module adding UX requirements to ease mass mailing of event track speakers.
        

## Installation

```bash
pip install odoo-bringout-oca-ocb-mass_mailing_event_track
```

## Dependencies

- website_event_track
- mass_mailing
